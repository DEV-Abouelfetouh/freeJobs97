# 💰 نظام كشف الرواتب والتحقق

نظام ويب يعمل بدون خادم (Client-side) لإدارة رواتب الموظفين، مع صلاحيات مدير وموظف.
كل البيانات تُخزّن محلياً في المتصفح (localStorage) — لا شيء يُرسل لأي خادم.

## 🚀 التشغيل

1. نزّل الملفات الأربعة في مجلد واحد.
2. افتح `index.html` في المتصفح (Chrome / Edge / Firefox).
3. سجّل الدخول بحساب المدير الافتراضي:
   - اسم المستخدم: `admin`
   - كلمة المرور: `admin123`

## 📁 بنية الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | الواجهة (تسجيل الدخول + لوحة المدير + لوحة الموظف) |
| `styles.css` | التنسيق (يدعم RTL والعربية) |
| `app.js` | كل المنطق (الاستيراد، التحليل، الحسابات، التحقق) |
| `sample-data.csv` | ملف تجريبي لاختبار الاستيراد |

## 📊 صيغة ملف Excel

يجب أن يحتوي الملف على الأعمدة التالية (عربي أو إنجليزي):

| الحقل | الأسماء المدعومة |
|---|---|
| الاسم | `name`, `اسم`, `الاسم`, `اسم الموظف`, `employee name` |
| الغياب | `abcen`, `absent`, `غياب`, `الغياب`, `absence days` |
| الخصم | `minus`, `deduction`, `خصم`, `الخصم` |
| الراتب | `salary`, `basic`, `راتب`, `الراتب` |
| صافي الراتب | `natSalary`, `net salary`, `صافي`, `صافي الراتب` |

**الصيغة المدعومة:** `.xlsx` / `.xls` / `.csv`

## 👥 الأدوار

### المدير (`admin`)
- استيراد ملف Excel عبر السحب والإفلات.
- عرض ملخص إحصائي شامل (إجمالي، فروقات، اعتراضات).
- البحث والتصدير إلى Excel.
- إدارة حسابات المستخدمين (إضافة / حذف).
- مراقبة حالة التحقق لكل موظف.

### الموظف (`emp1`, `emp2`, ...)
- يرى راتبه فقط.
- يستطيع تأكيد صحة البيانات أو إرسال اعتراض مع ملاحظة.
- يستطيع تغيير كلمة المرور الافتراضية.

## ⚠️ تنبيهات

- **غيّر كلمة مرور المدير** من `admin123` فوراً بعد أول دخول.
- كلمات المرور تُخزّن كنص صريح في `localStorage` — هذه نسخة تعليمية/محلية فقط. للإنتاج استخدم خادماً وقاعدة بيانات وتشفير كلمات المرور (مثل bcrypt).
- حذف بيانات المتصفح (Clear Browsing Data) يمحو كل شيء.

## 🧪 اختبار سريع

1. سجّل الدخول كـ `admin`.
2. استورد `sample-data.csv`.
3. لاحظ الحسابات المُنشأة: `emp1`, `emp2`, ...
4. اخرج وسجّل الدخول بحساب `emp1` (كلمة المرور `1234`).
5. جرّب تأكيد البيانات أو الاعتراض.
6. عُد للمدير لرؤية حالة التحقق.

## 🌐 اللغة

- واجهة عربية بالكامل (RTL).
- أسماء الأعمدة تُدعم بالعربية والإنجليزية.
