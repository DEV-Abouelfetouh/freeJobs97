

## 1. Princanoo — One-Page Coffee Shop Website
**Folder:** `01-princanoo-coffee-website/`

- Single-page, fully responsive website (mobile, tablet, desktop)
- Bilingual **English / Arabic** with language switcher and full RTL support
- **WhatsApp click-to-chat** button (pre-filled message) + **email** contact button
- Sections: hero, about, menu highlights, location & hours, contact
- Files: `index.html` + `README.md` (no build tools, ready to deploy)

## 2. Excel Data Analyzer — Simple Web
**Folder:** `02-excel-data-analyzer-web/`

- Simple web app that lets the user upload an **Excel file** (`.xlsx` / `.xls`)
- Reads the file and **fills the data** into a clean table view
- Quick summary of the data (rows, columns, totals, etc.)
- Files: `index.html` (+ any assets) + a short note on how to use and edit it
